# Food Menu Management System

A full-stack Food Menu Management System built using ASP.NET Core Web API, Entity Framework Core and Angular.

## Technologies

### Backend
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

### Frontend
- Angular
- TypeScript
- HTML
- CSS

## Features

- Add food items
- View food items
- Update food items
- Delete food items
- Filter food items by category
- Filter available food items

## Project Architecture

Layered Architecture.
